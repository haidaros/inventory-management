Architecture overview

Factory Inventory Management System

A demo full-stack dashboard for inventory, orders, demand, spending and reporting. A Vue 3 single-page app talks to a FastAPI service that serves in-memory data loaded from JSON files. There is no database: everything resets when the server restarts.

System architecture

Three tiers running locally: browser SPA, HTTP API, and static JSON data held in memory.

Data flow: changing a filter

The core loop of the app. Four global filters drive what every view shows.

  1. User picks a filter in FilterBar

    Time period, warehouse, category or order status.

  2. Shared state updates

    useFilters holds module-level refs, so every view sees the same values (singleton pattern).

  3. View reacts

    A watch on the four refs re-runs the view's load function, which calls getCurrentFilters().

  4. api.js builds the request

    Values equal to "all" are dropped; the rest become query params.

  1. FastAPI filters in memory

    apply_filters() then filter_by_month() run list comprehensions over the loaded data. Quarters expand via QUARTER_MAP.

  2. Response is validated

    Pydantic response_model shapes and checks the output.

  3. View stores raw data in refs

    For example allOrders, inventoryItems.

  4. Computed properties derive the UI

    KPIs, chart series and tables are computed, so they update automatically.

Things worth knowing

  • The tasks and purchase-order endpoints are missing. api.js calls /api/tasks and /api/purchase-orders, but main.py doesn't define them, so those calls return 404. The tasks panel still renders because it merges in mock tasks from useAuth.
  • Backlog.vue exists but has no route in main.js. Backlog data reaches users through the Dashboard instead.
  • Inventory has no time dimension, so the period filter doesn't affect inventory results.
  • Month filtering is a substring match on order_date, and quarters are hard-coded for 2025 only.
  • The dashboard backlog count ignores filters: total_backlog_items always counts every backlog item.
  • Auth is mocked: useAuth returns a fixed user. There is no login and no auth on the API.
